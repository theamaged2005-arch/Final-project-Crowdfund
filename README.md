# Crowdfund EG - Graduation Project

A Django-based crowdfunding platform for Egypt, allowing users to create fundraising campaigns, donate, comment, rate projects, and get help from a built-in FAQ chatbot.

## Features
- Custom authentication (Egyptian phone validation, email activation, forgot password)
- Project creation with categories, tags, multiple pictures, start/end dates
- Donations, comments with replies, ratings, reporting
- Homepage with top-rated slider, latest/featured projects, categories, search
- Offline FAQ-based AI chat assistant
